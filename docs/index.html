🔐 API - Fidelidade & Vendas

Documentação Interativa das APIs com Suporte a Múltiplos Identificadores

✨ Recursos Principais

  • Busca por múltiplos identificadores: CodigoCliente, CodigoCadastro ou CPFCNPJ (com/sem máscara)
  • Dados enriquecidos: Vendedor, Convênio, Forma de Pagamento, Auditoria Completa
  • Resgates de fidelidade: Histórico completo com pontos e prêmios
  • Histórico de compras: Análise detalhada de vendas por cliente

🚀 Como Usar

Buscar cliente por CPF (com máscara):
GET /fidelidade-resgate/cliente/123.456.789-00

Buscar cliente por CNPJ (sem máscara):
GET /vendas/cliente/12345678901234

Buscar cliente por CodigoCliente:
GET /vendas/cliente/123

📚 Endpoints Disponíveis

🎁 GET /fidelidade-resgate/cliente/{identificador} 🛍️ GET /vendas/cliente/{identificador}
